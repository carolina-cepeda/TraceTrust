# Diagramas de producto

Estos SVG están preparados en formato 16:9, con texto editable/legible y una
paleta consistente con el dashboard de TraceTrust.

- `01-architecture.svg`: diapositiva de arquitectura por capas.
- `02-analytical-pipeline.svg`: pipeline de procesamiento y análisis.
- `03-graph-model.svg`: modelo de nodos, relaciones y consultas.
- `04-global-drilldown.svg`: interacción de vista global hacia un lote.

Se pueden incorporar a la documentación del producto o convertir a PNG si se requiere una
imagen rasterizada. No representan infraestructura productiva; muestran el MVP
implementado y sus adaptadores preparados para una evolución operativa.
